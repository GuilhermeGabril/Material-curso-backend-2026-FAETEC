# 💻 Curso de Backend — FAETEC + SENAI

Repositório destinado aos códigos, exemplos e atividades desenvolvidos durante as aulas do **Curso de Backend**, realizado pela **FAETEC em parceria com o SENAI**.

O objetivo deste repositório é servir como material de apoio para os alunos, permitindo consultar e acompanhar os códigos desenvolvidos ao longo do curso.

---

## 📖 Como utilizar este repositório

A recomendação é acompanhar o conteúdo de acordo com a sequência das aulas.

Cada aula possui sua própria pasta, contendo os códigos desenvolvidos durante o encontro.

Para acompanhar uma aula específica:

1. Acesse a pasta da disciplina.
2. Escolha a pasta correspondente à aula.
3. Consulte os arquivos e códigos desenvolvidos.
4. Execute os exemplos localmente quando necessário.
5. Faça as alterações e exercícios propostos durante as aulas.

---

## 🚀 Executando os projetos

Alguns projetos poderão exigir a instalação de determinadas ferramentas ou dependências.

Quando necessário, cada projeto terá suas próprias instruções para execução.

Para projetos Node.js, por exemplo:

```bash
npm install
```

e, dependendo do projeto:

```bash
npm run dev
```

ou:

```bash
npm start
```
